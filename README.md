# House of Amrut

A frontend prototype for the House of Amrut experience.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Tech Stack
- React
- Vite
- Tailwind CSS
- React Router
- Shadcn UI
